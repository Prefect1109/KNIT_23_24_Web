# Лабораторна робота 3

В лабораторній роботі реалізовано чотири Django проекти:

## Запуск всіх проектів одночасно

Для зручності тестування можна запустити всі чотири проекти одночасно на різних портах:

```
./run_all.sh
```

Це запустить:
- UserProfileLab на порту 8000
- ShopLab на порту 8001
- JsonResponseLab на порту 8002
- CourseLab на порту 8003

Логи кожного серверу зберігаються у відповідних .log файлах. Для зупинки всіх серверів натисніть Ctrl+C.

## 1. UserProfileLab (порт 8000)

Система профілів користувачів з маршрутами:
- Головна сторінка: http://127.0.0.1:8000/
- Список користувачів: http://127.0.0.1:8000/users/
- Інформація про конкретного користувача: http://127.0.0.1:8000/users/<username>/
- Список замовлень користувача: http://127.0.0.1:8000/users/<username>/orders/

Для запуску окремо:
```
cd UserProfileLab
./run.sh
```

## 2. ShopLab (порт 8001)

Магазин з динамічними категоріями:
- Головна сторінка магазину: http://127.0.0.1:8001/
- Категорії товарів: http://127.0.0.1:8001/shop/<category>/
- Товари в категорії: http://127.0.0.1:8001/shop/<category>/<product>/
- Акції: http://127.0.0.1:8001/shop/sale/

Для запуску окремо:
```
cd ShopLab
./run.sh
```

## 3. JsonResponseLab (порт 8002)

Відправка JSON-відповіді з інформацією про користувача:
- Отримати список користувачів: http://127.0.0.1:8002/api/users/
- Отримати інформацію про конкретного користувача: http://127.0.0.1:8002/api/users/Іван/

Для запуску окремо:
```
cd JsonResponseLab
./run.sh
```

## 4. CourseLab (порт 8003)

Система курсів із багаторівневою маршрутизацією:
- Список курсів: http://127.0.0.1:8003/courses/
- Деталі курсу: http://127.0.0.1:8003/courses/<course_name>/
- Модулі курсу: http://127.0.0.1:8003/courses/<course_name>/modules/
- Деталі модуля: http://127.0.0.1:8003/courses/<course_name>/modules/<module_id>/

Для запуску окремо:
```
cd CourseLab
./run.sh
```
